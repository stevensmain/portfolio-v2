# Portfolio

Este es mi portfolio personal construido con Astro, React, TypeScript y Tailwind CSS. El proyecto presenta una experiencia moderna y atractiva para mostrar mis proyectos, experiencia y habilidades.

## 🛠️ Tecnologías

- [Astro](https://astro.build/) - Framework web moderno
- [React](https://reactjs.org/) - Biblioteca UI
- [TypeScript](https://www.typescriptlang.org/) - Superset de JavaScript
- [Tailwind CSS](https://tailwindcss.com/) - Framework CSS
- [Three.js](https://threejs.org/) - Biblioteca 3D
- [ScrollReveal](https://scrollrevealjs.org/) - Animaciones al scroll

## 📦 Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/portfolio-v2.git
cd portfolio-v2
```

2. Instala las dependencias:

```bash
pnpm install
```

3. Inicia el servidor de desarrollo:

```bash
pnpm dev
```

## 🏗️ Scripts Disponibles

- `pnpm dev` - Inicia el servidor de desarrollo
- `pnpm build` - Construye el proyecto para producción
- `pnpm preview` - Vista previa de la build
- `pnpm lint` - Ejecuta el linter
- `pnpm lint:fix` - Corrige problemas de linting
- `pnpm format` - Formatea el código
- `pnpm format:check` - Verifica el formato del código

## 🧪 Testing

```bash
# Ejecutar tests
pnpm test

# Ejecutar tests en modo watch
pnpm test:watch
```

## 📝 Convenciones de Código

- Seguimos las convenciones de TypeScript
- Utilizamos ESLint y Prettier para el formato del código
- Los componentes siguen el patrón de diseño Atomic
- Los nombres de archivos usan kebab-case
- Los componentes React usan PascalCase
